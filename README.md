<summary><strong>🇬🇧 English</strong></summary>

CleanGrab is a small Windows app that lives in your system tray. Copy a YouTube, TikTok, Instagram or Spotify link, and a little card slides in to save it as MP3 or MP4 in one click.

Everything happens on your own computer — **no account, no ads, no analytics.**

### ✨ Features
- 📋 Clipboard-aware — copy a link, get an instant save prompt
- 🎧 MP3 or MP4 — pick your format in one click
- 🔒 100% local — no account, no cloud, no tracking
- 🔄 Self-updating — checks for new versions and installs them for you

### 📥 Download
1. Open the [latest release](../../releases/latest).
2. Under **Assets**, download `CleanGrab_x.y.z_x64-setup.exe`.
3. Run it — it installs for your account only and needs no administrator rights.

> **Note:** Windows may show *"Windows protected your PC"* because the installer isn't code-signed yet. Choose **More info** → **Run anyway**.

### 🔄 Updates
Once installed, CleanGrab checks this repository once a day for a new release. When one is available, it can download and install it for you, right from the app. Turn this off anytime in **Settings → About → Updates**.

### 🔐 Privacy
CleanGrab has no account, no ads, and no analytics. Links are checked entirely on your computer. The only thing the app asks this repository for is the latest version number — and, if you accept an update, the new installer.

See [PRIVACY.md](PRIVACY.md) for the full privacy policy, and [TERMS.md](TERMS.md) for the terms of use.
